# LOW Launcher

Сторонний лаунчер для запуска Minecraft: установка версий в пару кликов, отдельные сборки с изолированными папками модов, встроенный менеджер модов, автообновление, Discord Rich Presence.

> Проект с закрытым исходным кодом. Исходники не публикуются и не распространяются.

## Отказ от ответственности

Этот проект **не связан с Mojang AB, Microsoft или Minecraft** и не одобрен ими. «Minecraft» — товарный знак Mojang Synergies AB / Microsoft. LOW Launcher — независимый инструмент для запуска игры, использующий официальные ресурсы Mojang для загрузки версий Minecraft (сами файлы игры не изменяются и не распространяются в составе лаунчера).

Поддержка стороннего входа реализована через открытый протокол **Ely.by** — независимый сервис учётных записей, публично документированный и используемый множеством сторонних лаунчеров.

## Возможности

- **Вход через Ely.by** — авторизация в системном браузере, без ввода пароля в самом лаунчере. Также доступен обычный вход по нику.
- **Установка версий** — Vanilla, Forge, NeoForge и Fabric в пару кликов, файлы загружаются напрямую с официальных серверов Mojang/Forge/Fabric. Есть опция показывать и тестовые снапшоты.
- **Сборки** — несколько отдельных профилей под одну и ту же версию, у каждого своя папка модов, миры и настройки не пересекаются. Сборки можно экспортировать в .zip и импортировать обратно — например, чтобы перенести на другой компьютер или поделиться с другом.
- **Менеджер модов (Modrinth)** — поиск и установка модов, ресурспаков и шейдеров прямо в лаунчере, с автоматической подгрузкой обязательных зависимостей. Модпаки (.mrpack) ставятся в один клик как отдельная новая сборка.
- **Скины Ely.by в мультиплеере** — опциональный фикс для Fabric/Forge/NeoForge сборок, чтобы скин был виден другим игрокам на сервере, даже если сам сервер для этого не настроен.
- **Автоматическая Java** — подбор и загрузка нужной версии Java под установленную сборку.
- **Автообновление** — лаунчер сам проверяет и устанавливает новые версии в фоне.
- **Оформление** — несколько готовых тем и возможность задать свои цвета.
- **Discord Rich Presence** — необязательный статус активности в Discord.
- **Отчёты о вылетах** — при сбое игры лаунчер помогает быстро найти и открыть журнал ошибки.
- **Во время игры** — лаунчер прячется, пока запущен Minecraft, и появляется снова после выхода из игры.
- **Консоль** — лог запуска для диагностики проблем.
