# LOW Launcher

Сторонний лаунчер для запуска Minecraft: установка версий в пару кликов, отдельные профили с изолированными папками модов, автообновление, Discord Rich Presence.

> Проект с закрытым исходным кодом. Исходники не публикуются и не распространяются.

## Отказ от ответственности

Этот проект **не связан с Mojang AB, Microsoft или Minecraft** и не одобрен ими. «Minecraft» — товарный знак Mojang Synergies AB / Microsoft. LOW Launcher — независимый инструмент для запуска игры, использующий официальные ресурсы Mojang для загрузки версий Minecraft (сами файлы игры не изменяются и не распространяются в составе лаунчера).

Поддержка стороннего входа реализована через открытый протокол **Ely.by** — независимый сервис учётных записей, публично документированный и используемый множеством сторонних лаунчеров.

## Возможности

- **Вход через Ely.by** — авторизация в системном браузере, без ввода пароля в самом лаунчере. Также доступен обычный вход по нику.
- **Установка версий** — Vanilla, Forge и Fabric в пару кликов, файлы загружаются напрямую с официальных серверов Mojang/Forge/Fabric.
- **Профили** — несколько отдельных сборок под одну и ту же версию, у каждой своя папка модов, миры и настройки не пересекаются.
- **Автоматическая Java** — подбор и загрузка нужной версии Java под установленный профиль.
- **Автообновление** — лаунчер сам проверяет и устанавливает новые версии в фоне.
- **Discord Rich Presence** — необязательный статус активности в Discord.
- **Отчёты о вылетах** — при сбое игры лаунчер помогает быстро найти и открыть журнал ошибки.
- **Консоль** — лог запуска для диагностики проблем.
